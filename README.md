# GTM Event Tracker

The solution is designed as a centralized go-to-market event management application built on the SAP Cloud Application Programming Model and delivered through SAP Fiori Elements. Its primary goal is to provide a single, consistent source of truth for planning, executing, and monitoring events while minimizing manual coordination effort. All relevant event data is captured in a structured domain model, ensuring that information about events, responsibilities, tasks, and costs is tightly integrated and always up to date.  At the core of the application is the event entity, which represents a go-to-market event and serves as the aggregation point for all related information. Each event contains general details such as date, location, status, and expected number of guests, as well as references to responsible persons and associated tasks. Responsibilities can be assigned both at event level and task level, enabling clear accountability and transparent ownership throughout the planning and execution phases. Tasks follow a defined lifecycle with statuses such as open, in progress, and done, allowing users to easily track progress and identify bottlenecks directly from the event overview and detail views.  Cost-relevant information is managed as an integral part of the event. Catering and beverage services are maintained with prices per person and linked to the event’s guest count. Based on this data, total costs are calculated automatically and updated in real time whenever prices or guest numbers change. This ensures continuous cost transparency and allows planners to assess the financial impact of decisions early, without relying on external calculations or spreadsheets.  The application leverages standard SAP Fiori Elements floorplans, such as list reports and object pages, to provide a consistent, role-based user experience with minimal custom UI development. Users can access an overview of all planned events, apply filters by status or responsible person, and quickly navigate to detailed event pages where tasks, responsibilities, and costs are displayed in a clear and structured way. CAP services expose the underlying data and business logic in a clean and extensible manner, enabling future enhancements such as analytics, approval workflows, or integration with other SAP systems.  Overall, the solution establishes a scalable and maintainable foundation for go-to-market event management. By combining a robust backend model with a standardized and intuitive user interface, it improves transparency, collaboration, and cost control, while significantly reducing manual effort and operational risk during event planning and execution.
